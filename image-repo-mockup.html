Visits mode

Images mode

  • • Unit of data: the image
  • • Fraud filter = "image has this exact flag"
  • • Mode filters: Search, Asset type, Retailer
  • • Backend: GET /images?flag=bad_angle&date=...
  • • Returns only matching images, no extras
